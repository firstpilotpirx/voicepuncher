**Reason**: Text refinement through a local language model is removed from the product: the transcript of speech recognition is good enough to paste as is, and the refinement step only added latency, a third model service on the GPU and longer checks.
**Migration**: None; dictations are pasted as transcribed, without filler sounds (text-insertion). An old configuration file that still holds text refinement settings keeps loading.
