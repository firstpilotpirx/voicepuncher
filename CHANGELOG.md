# Changelog

The changes of every version are the release notes of its [GitHub Release](https://github.com/firstpilotpirx/voicepuncher/releases): `just release` writes them from the merged pull requests when it tags `vX.Y.Z`. Versions follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html); before 1.0.0 a breaking change or a new capability bumps the minor version, a fix the patch version.
